## C. 调用与引用类（P16–P17）

### P16 · 跨库漏改能静默两个月

| 项 | 内容 |
| :--- | :--- |
| 事故 | 2026-11-11 资源库两层重构，母体 B 改了，**母体 A 的素材清单没跟** |
| 规模 | 199 行 / **591 条路径全部指空** |
| 为什么没报错 | 表里存的是字符串，不是超链接 |
| 修复 | 重定基 4 组前缀 + 补 10 角色 + 修 6 条存量脏路径 → 627/627 可达 |
| 正确做法 | 改前广播「旧前缀 → 新前缀 + 生效时间 + 影响判据」；引用方进常态化体检（`tools/check_table_paths.py`） |

同类隐患：同期母体 A 的 `角色辞典.json` 有 598 处资源引用，也是靠事后补检才确认全通。

### P17 · 索引整篇改名等于伪造历史

| 做法 | 结果 |
| :--- | :--- |
| 全文替换 `01_角色` → `10_用户层\11_角色立绘` | 「2026-10-21 实测 5,667 文件」这类陈述失去依据 |
| **保留原文 + 新增「口径换算」节** | 历史陈述仍成立，读者按表换算 |

实测：`资源总清单.md` 476 行一字未改，只在文件头加 §零（15 行对照 + 一句为什么）。

**例外**：纯查找型索引可以全文替换，因为它不承载历史数字。

## D. 清理与去重类（P18–P19）

### P18 · 去重优先级必须显式定序

| 事故 | 后果 |
| :--- | :--- |
| 优先级把「临时车间」排在「母体资源库」之上 | `00_资源库\01_角色` 的部分立绘被当冗余移走，**全量回滚** |
| 备份目录与被备份目录同 MD5，优先级判错 | Bot 的 `plot_docs.jsonl` 被当重复副本移走，剧情索引**从 2,514 条掉到 0 条** |

正确顺序（数字小的优先保留）：

```
母体资源库(10) < 母体其他(15) < 工位产物(20) < 工位其他(30) < 临时车间(50) < 回收站(80) < 归档(90)
```

> **口诀：去重时「活体 / 母体」永远排在「备份 / 临时」之上。**

### P19 · 工具链本身会踩坑

| 坑 | 现象 | 正确做法 |
| :--- | :--- | :--- |
| Python 回收站组件 | 删空目录报 `HRESULT 0x80040154`（类未注册），**空壳目录删不掉** | 改用 shell `find -type d -empty -delete` |
| shell 传多级反斜杠 | 经 shell 传递时二次转义成 `\\`，路径改写失败 | 路径改写**一律落 `.py` 文件执行**，禁止 `python -c` 内联中文 + 反斜杠 |
| 搬迁后外部注册未同步 | 计划任务启动失败 `0x8007010B`（找不到路径） | 改完目录立即改 Action，并同步任务定义 xml 副本 |
| journal 未落盘 | 1,000 次扁平移动无记录，无法回溯 | 移动前写 journal，**每次移动先 append 再执行** |

## E. 反向清单：这些「看起来像坑」但不是

| 项 | 为什么不是坑 |
| :--- | :--- |
| `Sprite` 与 `Texture2D` 同源 | 一个是裁过透明边的切片，一个是全画布，**不是重复，不去重** |
| `_tex` 后缀 | 国服原生后缀，`_intl` 才是人工加的，不代表同物 |
| 4 张点唱机封面与图标库版本同名不同内容 | 像素差 91–99%、无 ICC，属**不同批次提取**，两处各自保留 |
| 称号 `_待定\` 与 `国服HD\` | 96 个差异像素全在 `alpha=0` 透明区，视觉等价，保留 `国服HD` 那份 |
| `24_` 编号空缺 | 规划过但需求没落定，**不占位是正确做法** |
