# 模板说明

三张表的标准表头。CSV 均带 UTF-8 BOM，Excel 双击打开不乱码。

| 文件 | 对应规范 | 关键列 | 更新方式 |
| :--- | :--- | :--- | :--- |
| `入库登记.csv` | `03_入库\登记与防重.md` §2 | `库内路径`（唯一真正必需） | 每批次新建一份，**不追加** |
| `路径迁移映射.csv` | `02_调用\映射与重定基.md` §1 | `旧路径,新路径` | 迁移时生成，永久保留 |
| `取件表.csv` | `02_调用\定位协议.md` §3 | `local`（相对库根） | 滚动，**只留最新 1 份** |

---

## 为什么入库登记用 `库内路径` 而不是 `落盘相对路径`

三个理由：

1. **和取件表对齐** —— 取件表的 `local` 就是相对库根的路径，同一语义同一措辞
2. 「落盘相对路径」有歧义：相对谁？相对采集目录也是「相对」
3. 它是唯一真正必需的列，值得一个不会误解的名字

存量表的兼容映射见 `03_入库\登记与防重.md` §2.3。

---

## 三张表的关系

```
入库登记   ← 累积：这个文件是不是入过库（按批次分文件）
   ↓ 采集落地
路径迁移映射 ← 一次性：搬家时哪个文件去了哪
   ↓ 结构变更
取件表     ← 滚动：当前每个槽位该从哪个目录取
```

**只有取件表是滚动文件**。判断口诀：读哪份有唯一答案的是滚动，有哪些批次有意义的是累积。
